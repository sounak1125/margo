# Welcome to Margo 👋

Margo is your friendly home for **documents, spreadsheets, and notes** — it reads and writes Markdown, Word, and Excel files, fully offline.

## What Margo can do

- ✏️ **Markdown** — write with a live side-by-side preview
- 📄 **Word documents** (`.docx`) — rich text editing on a clean page
- 📊 **Spreadsheets** (`.xlsx` / `.csv`) — a proper grid with multiple sheets
- 🔄 **Convert on save** — save a note as `.docx`, a document as `.md`, a sheet as `.csv`

## Handy shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save As… |
| `Ctrl+O` | Open a file |

> Tip: drag any supported file onto the window and Margo opens it.

## A little code, for flavor

```js
const mood = "cozy";
console.log(`Writing feels ${mood} in Margo`);
```

Have fun — and if you break something, `Ctrl+Z` has your back.
